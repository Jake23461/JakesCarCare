# Client Images

Place real client photos in this folder and keep filenames kebab-case.

## Recommended folders

- `exterior/` for storefront, van, team-on-site, or street presence photos
- `interior/` for space, atmosphere, and environmental details
- `services/` or `products/` for close-up work examples, dishes, treatments, finished installs, and similar
- `logos/` for wordmarks, transparent brand assets, and alternate logo exports
- `ai-kit/` for Nano Banana outputs generated by `node scripts/generate-visual-kit.mjs`

## AI Kit

The visual-kit generator writes timestamped runs into:

```text
public/images/ai-kit/<timestamp>/
```

Each run contains:

- generated image assets
- `manifest.json`
- prompt text files for reuse and iteration

## Usage in code

```tsx
import Image from "next/image";

<Image
  src="/images/ai-kit/2026-04-07-204500/hero-primary.png"
  alt="Atmospheric hero image for the business"
  fill
  className="object-cover"
/>
```

## Recommended formats

- JPG or WebP for photography-heavy assets
- PNG only when transparency is needed
- 1200px to 2400px wide for hero images
- 800px to 1400px wide for card and section images
